# iKnow - App de culture générale

## Stack
- React Native + Expo (managed workflow)
- Supabase (Postgres + auth anonyme)
- expo-notifications

## Objectif
App qui délivre 1 question de culture générale par jour via notification, avec QCM 4 réponses, feedback + explication, historique, streak, récap hebdomadaire.

## Commandes
- Lancer l'app : npx expo start
- Installer un paquet : npm install [nom]

## Conventions
- Composants en TypeScript
- Un fichier = un composant
- Toujours m'expliquer le "pourquoi" des choix techniques, pas juste le code
